## Getting Started
The Domain project contains the product’s core business concepts and rules. It should represent the problem the product solves, independently of user interface and infrastructure technologies.

This project should have no dependency on WPF, Entity Framework, SQLite, device SDKs, or other application projects.

Typical contents: domain entities, value objects, domain rules, enums, and domain events.

## Responsibility
core business concepts and rules

## Dependencies
Don't depend on any other project.
